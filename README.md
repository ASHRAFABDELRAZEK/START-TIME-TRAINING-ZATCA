# START TIME — محاكي رفع الإقرارات (تدريبي)

**موقع تدريبي خاص بالتدريب على رفع الإقرارات فقط — ليس له أي علاقة بهيئة الزكاة والضريبة والجمارك ولا بأي جهة حكومية.**
إعداد **ASHRAF FATHY — START TIME ACADEMY**.

- الرابط: https://ashrafabdelrazek.github.io/START-TIME-TRAINING-ZATCA/
- بيانات الدخول ثابتة ومقفولة (تدريبية)، ورمز التحقق ثابت 1234. لا يُطلب ولا يُرسل أي بيانات حقيقية.
- تقدم المتدرب يُحفظ على جهازه فقط.
- **قوالب Excel:** من زرار «قوالب Excel» تنزّل قالب الإقرار (القيمة المضافة / نموذج 10 / الاستقطاع الشهري)، تعبيه، وترفعه للمراجعة. الملف بيتقري على الجهاز ولا يُرفع لأي مكان.

> تنبيه: الأرقام اللي بيطلعها المحاكي تقريبية لأغراض التدريب والمراجعة المبدئية. هيئة الزكاة والضريبة والجمارك هي الجهة الوحيدة المختصة بحساب المستحق واعتماده، والمرجع هو البوابة الرسمية والأنظمة واللوائح.

## أدوات التدريب
- **اكتشف الخطأ**: 4 تمارين (قيمة مضافة، مقاولات، استقطاع، زكاة) فيها أخطاء شائعة.
- **الوعاء الزكوي خطوة بخطوة**: حاسبة تقريبية للتعلّم فقط.
- **قاموس المصطلحات**.
- **تقرير الأداء**: سجل محلي على الجهاز بيتنزل Excel للمدرب.
- **وضع المدرب**: افتح الرابط بـ `?trainer=1` عشان تظهر الإجابات ومفتاح الحلول.
