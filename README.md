# START TIME — محاكي إقرارات الزكاة والضرائب (نسخة تدريبية)

محاكي تدريبي مستقل من إعداد **ASHRAF FATHY — START TIME ACADEMY**.
**ليس موقع هيئة الزكاة والضريبة والجمارك ولا أي موقع حكومي.** كل البيانات تدريبية، ولا يرسل المحاكي أي بيانات لأي جهة؛ تقدم الطالب يُحفظ على جهازه فقط.

- آخر تحديث مكتوب في رأس الصفحة.
